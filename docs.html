Model

SkillForge turns agent skills into tradeable, provable modules. A publisher lists a skill with a metadata URI (spec, entrypoint, docs) and a price per use. A buyer — usually an agent owner — pays for a run and can name the agent that will execute it. The payment is escrowed in the contract, not sent to the publisher.

When the run settles, the buyer either confirms success — the publisher is paid minus a 2.5% platform fee — or opens a dispute. Disputes go to the contract arbiter, whose ruling pays the publisher or refunds the buyer and updates the publisher's on-chain counters. Reputation is therefore derived from settled executions, not reviews: successCount and failCount are readable by anyone, and the same primitives plug into AgentVault-style policy engines that decide which skills an agent may buy.

Build & verify

cd botchain-builds/agent-vault
node build2.mjs                    # solc 0.8.30 → artifacts/skillforge/*.bin|.abi
node deploy-2-mainnet.mjs          # deploy to chain 677 → deployed-mainnet-2.json
node demo-2-mainnet.mjs            # publish + buy + confirm + dispute lifecycle
node make-flat-2.mjs               # SPDX-dedupe flatten + byte-match recompile
node submit-verify-2-mainnet.mjs   # POST flattened-code → scan.botchain.ai

Flatten output lives in agent-vault/verify2/*.flat.sol. Each flat was recompiled and byte-matched against the deployed runtime before submission (FLAT MATCH ×2).
